# Contributing

Use Python standard-library tests and keep the two native shells small. Validate changes with `python3 scripts/test.py`; run platform-specific builds where available. Preserve database migration compatibility and never fabricate missing historical samples.

Please use synthetic fixtures. Do not commit databases, logs, SSIDs, private IP/MAC addresses from real networks, personal paths, credentials, or screenshots containing real usage history. Disclose which operating systems you actually tested.
