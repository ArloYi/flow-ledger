# 安装、升级与卸载

## Mac

下载 arm64 DMG，打开后将“流量手账”拖到 Applications。需要 Apple Silicon 和 macOS 13+。升级前先从菜单退出旧版，再替换应用。记录保存于当前用户的 `Library/Application Support/流量手账`，不随应用替换删除。

菜单底部的“登录 Mac 后自动记录”控制登录启动；登录时仅显示菜单栏，主窗口不会主动弹出。关闭窗口仍记录，退出应用停止。

卸载前取消登录启动，退出应用并移入废纸篓。默认保留历史；如需清空，可从菜单打开数据文件夹后自行备份、删除。安装包不带任何开发者历史。

## Windows

需要 Windows 10/11 x64。运行 `FlowLedger-1.5.0-beta.1-Windows-x64-Setup.exe`，确认后安装到当前用户的 `%LOCALAPPDATA%\Programs\FlowLedger`，创建名为 Flow Ledger 的桌面与开始菜单入口，并注册到 Windows“已安装的应用”。无需管理员权限，也无需另装 Python。

应用启动后出现在托盘，左键打开界面、右键打开菜单；“登录 Windows 后自动记录”通过当前用户启动文件夹快捷方式控制。首次安装默认不开启自启。

主窗口优先使用系统 Edge 独立窗口，没有 Edge 时用默认浏览器。浏览器只访问随机端口的 `127.0.0.1` 本地界面，采集不依赖页面打开。

升级前退出托盘应用，再运行新安装包。安装目录暂存旧版，替换完成后移除旧程序；流量数据库位于 `%LOCALAPPDATA%\FlowLedger`，不会被升级覆盖。

卸载：先从托盘退出，再到 Windows 设置 → 应用 → 已安装的应用，卸载“流量手账”。程序、登录启动入口和快捷方式移除，流量数据默认保留。便携 ZIP 解压后可直接启动，便携版的数据仍写入上述用户数据目录。

两个平台的预览包均未使用发布者证书签名；系统可能显示警告或阻止运行。不要关闭整个系统的安全防护。正式签名、公证与更多硬件验收仍在后续计划中。
