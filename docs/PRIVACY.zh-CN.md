# 隐私与发布检查

本机保存：日期/分钟用量、物理接口标识、经哈希的网络身份、用户自填的网络名称与类型、主动测速结果。不会采集浏览内容、数据包正文、账户密码或联系人。哈希标识不等于数据已经匿名化，因此数据库仍按私人数据处理。

普通记录不上传到服务器。主动测速将连接 Cloudflare 的公开端点，对方能够看到连接 IP；仅在用户确认后运行。中科大链接是独立网站，其用量和数据政策由该站决定，不自动测速或导入结果。

公开仓库仅包含源码、通用文档、合成测试夹具和依赖许可证。数据库、日志、用户网络名称、内部文档链接、本机截图和历史备份不进入仓库或安装包。测试中的网络名、地址和标识均为合成夹具。

发布前检查分三层：

1. 源码文件和 Git 待提交清单：检查密钥模式、私人路径、实际网络标识及非发布文件。
2. 安装包解包：检查 DMG 的应用资源、Windows 便携包及嵌入安装器的相同载荷，确认没有数据库或运行日志。
3. 上传后：复核远端文件清单、下载附件及校验值，与本地已审查产物一致。

自动扫描只能辅助发现问题，不能证明不存在所有隐私风险。请勿将自己的数据库、真实截图、日志或系统路径直接提交到 Issue。
